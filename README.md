# Residential Energy Consumption Forecasting

A Deep Learning mini-project for forecasting residential electricity consumption using a Transformer-based Self-Attention model.

## Objective

To predict future residential energy consumption using historical electricity consumption data and a deep learning time-series forecasting model.

## Model

Transformer-Based Self-Attention

## Project Workflow

1. Dataset collection
2. Data cleaning
3. Exploratory Data Analysis
4. Time-series preprocessing
5. Data normalization
6. Sequence generation
7. Transformer-based Self-Attention model
8. Model training
9. Future energy consumption prediction
10. Model evaluation
11. Actual vs Predicted analysis

## Evaluation Metrics

- MAE
- MSE
- RMSE
- MAPE
